1. Project Vision

The Smart Placement Portal is an advanced recruitment management system featuring automated resume scanning, skill profiling, and intelligent job recommendations driven by Machine Learning algorithms.

2. Technical Architecture

Frontend

Developed with React 19, utilizing a custom-built design system with glassmorphism and real-time toast notifications.

Backend

A Node.js/Express server providing a secure RESTful API. Authenticated via Stateless JWT with Bcrypt hashing for password security.

ML / Intelligence

A Python microservice that performs TF-IDF Vectorization and Cosine Similarity analysis to match student skills with job requirements.
